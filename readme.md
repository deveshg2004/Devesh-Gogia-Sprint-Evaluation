## 📌 Problem Statement

Large organizations often struggle to maintain accurate hardware inventory records. IT assets can be **misplaced, unreturned during employee offboarding, prematurely discarded, or difficult to trace** due to the lack of centralized lifecycle and ownership tracking.

The **IT Asset Lifecycle Manager** addresses these challenges by providing a secure and centralized application to:

- 📦 Track IT hardware from **procurement to retirement**
- 🔄 Maintain an **immutable ownership ledger** for asset transitions
- 📅 Enforce **data integrity rules** around distribution and assignment dates
- 🗄️ Prevent accidental deletion through **compliance-driven archiving**
- 🔐 Provide secure access using **Role-Based Access Control (RBAC)**
- ☁️ Deploy the application on **SAP Business Technology Platform (SAP BTP)**
